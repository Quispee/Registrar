Conexión a Base de Datos (Simulación)

Este sería el código PHP para conectarse a la base de datos MySQL:

<?php
$host = "localhost";
$usuario = "root";
$contrasena = "";
$base_datos = "sise";

$conexion = new mysqli($host, $usuario, $contrasena, $base_datos);

if ($conexion->connect_error) {
    die("Conexión fallida: " . $conexion->connect_error);
}
?>

⚠️ Recuerda que este código solo funciona con PHP. En HTML puro no puedes conectarte a una base de datos.
